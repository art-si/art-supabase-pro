# SQL 工作区与数据库连接

工作区支持当前 Supabase，以及通过独立执行端连接的 PostgreSQL、MySQL 8、达梦 DM8 数据库。左侧数据库资源面板默认 340px，可在 240–520px 间拖动；旧的窄版默认配置会升级一次，后续保留手动宽度。对象树使用 `ElTreeV2` 和项目规范的 `ElAutoResizer`，只渲染可见节点，按 schema 加载并缓存分支，支持整块收起、分组折叠、表／字段／函数搜索。分组采用手风琴布局，当前分组占用剩余高度并独立滚动，外层不再嵌套滚动条；分组入口保持可见。展开请求使用专用圆环图标指示加载，数据库图标保持静止。语句导航在首次只有一条语句时收起，多条时展开，并保存手动选择；用户已操作其他分组时不自动切走。

## 使用外接数据库

1. 项目开发服务启动时会自动检查并启动本机执行端。单独使用时，在当前仓库运行 `pnpm sql:gateway`；服务在后台运行，启动终端可以关闭。需要前台诊断时使用 `pnpm sql:gateway:foreground`。
2. 打开 SQL 控制台的“连接管理”会自动加载连接。默认执行端为 `http://127.0.0.1:4319`，手动地址配置位于“高级连接设置”；连接失败时可直接重新加载。
3. 平台超级管理员新建 PostgreSQL、MySQL 或达梦 DM8 连接，填写数据库的只读账号、所属租户和可使用的账号，测试后保存。DM8 默认端口 5236，“默认 schema”可留空使用账号默认模式；此处不是主机 IP。
4. 点击“使用”或从顶部连接选择器切换。每个查询页签绑定连接和数据库，最多打开 8 个页签；草稿和执行历史按账号、租户、连接目标、页签隔离。查询结果不持久化。
5. 展开 schema 加载表、视图、函数，再展开字段、索引和外键。双击或使用插入按钮载入对象名称；右键可以复制名称、生成 SELECT/COUNT 或查看结构。这些动作均不会自动执行查询。

外接执行端支持单条 SELECT / WITH 查询和仅预估的 EXPLAIN，使用数据库只读事务。默认返回 200 行、超时 10 秒，最多 1000 行、30 秒，单份响应最大 8 MB。MySQL 查询同时设置服务端执行时限；执行端限制每账号 2 项、全局 8 项并发。只读事务并不代替数据库账号的最小权限配置，普通账号应使用专门授予 SELECT 权限的数据源账号。

DM8 使用官方 `dmdb` 驱动，开启会话只读和事务只读，按 `ROWNUM` 限行。当前支持内网直连、查询及表／视图／字段／索引／外键／函数元数据；TLS 证书模式和执行计划暂不提供，执行计划入口会明确禁用。执行端启动器为 DM8 登录加密兼容单独启用 Node 的 legacy OpenSSL provider，不更改浏览器或全局 Node 环境。

达梦查询区可显式选择“当前 schema”，也可在 schema 的对象菜单中设置，或双击 schema 激活。展开树节点本身不切换 SQL 执行范围。未限定表名会在当前 schema 下查找；也可使用 `"APP_SCHEMA"."TABLE_NAME"` 完整限定名。选择按查询页签保存，新页签继承当前选择；历史、SQL 收藏和 AI 请求保留 schema 上下文。切换范围会清空旧结果并丢弃旧请求的晚到响应。

## 连接与租户权限

- 当前 Supabase 的原始 SQL 执行和执行计划仍只允许平台超级管理员；普通用户可按既有授权浏览结构、使用 AI。
- 外接连接由平台超级管理员管理。平台“全部租户”可管理所有连接，选择具体租户后仅能管理该租户连接；新建连接默认属于当前选择的租户，全部租户模式默认属于管理员自身租户。
- 普通用户仅能使用自己所属租户、已启用、且显式授权给自己的连接。服务端从 Supabase Auth 与启用状态的 `sys_user` 重新确定身份，忽略普通用户伪造的租户范围。
- 授权账号可读取该数据库账号可见的数据；外部数据库没有自动继承当前业务系统的行级租户规则。应按数据范围配置独立的只读数据库账号，再授予连接使用权。
- 可以编辑或停用连接；连接配置与授权变化后，执行端不会交付旧配置的查询结果。已保存连接不可直接改变所属租户。

## 执行端部署与凭据

执行端使用当前项目 `.env` 中的公开 `VITE_SUPABASE_URL`、`VITE_SUPABASE_KEY` 验证平台身份，固定作用于项目 `ckbftoopuyophiebamwy`；不需要把服务角色密钥放入浏览器。

连接密码使用 AES-256-GCM 保存，仅执行端持有密钥。默认目录为当前操作系统用户的 `.art-sql-workbench/ckbftoopuyophiebamwy`，Unix 目录/文件权限分别为 0700/0600，Windows 限制为当前用户 ACL。应连同 `vault.key` 和 `connections.json` 一起备份并限制访问；丢失密钥无法恢复已有密码。浏览器的缓存、草稿和页签不保存密码。审计写入 `audit.jsonl`，记录操作者、租户、连接、动作、结果和请求编号，不记录 SQL、结果内容、密码或登录令牌。

可选环境变量：

| 变量 | 用途 |
| --- | --- |
| `SQL_GATEWAY_PORT` | 监听端口，默认 4319 |
| `SQL_GATEWAY_HOST` | 监听地址，默认 127.0.0.1 |
| `SQL_GATEWAY_STATE_DIR` | 执行端凭据与审计目录 |
| `SQL_GATEWAY_ALLOWED_ORIGINS` | 额外允许的前端站点 origin，逗号分隔，不使用通配符 |
| `VITE_SQL_GATEWAY_ORIGINS` | 前端构建时配置允许携带登录令牌访问的远程 HTTPS 执行端 origin，逗号分隔 |

默认允许前端 `http://127.0.0.1:3006`、`http://localhost:3006`、`https://art-si.github.io`，以及本机网卡地址上配置端口的项目地址；开发服务启动时也传入其实际前端 origin。来源必须精确匹配，不使用通配符。内网数据库由能访问它的执行端连接；可在本机运行，也可在内网服务器运行并通过经过认证配置的 HTTPS 反向代理提供服务。远程部署时须在前端构建配置中加入可信执行端地址，并在执行端加入实际前端站点来源；数据库密码不出现在 URL 中。HTTP 仅支持回环地址，远程连接须使用 HTTPS。执行端与浏览器均会拒绝未配置的来源或远程执行端地址。

## 对象与编辑器工具

- 常用对象可以收藏和取消收藏，支持一键收起全部对象。索引可查看带高亮的定义；没有 DDL 的索引显示结构化 JSON。外键可直接查看关联表结构。
- 对象菜单按类型提供查询模板、新页签查询、主键筛选、行数与空值统计、字段去重与频次、数值范围、复合外键关联查询，以及名称／字段列表／结构 Markdown／结构 JSON 复制。右键、行内“更多操作”和 Shift+F10 均可打开；支持方向键、Home/End、Esc 和长列表滚动。SQL 操作只载入，不自动执行。
- 搜索支持已加载对象的名称、字段和注释，并展示匹配字段；未展开的 schema 按需加载。
- SQL 收藏保存当前脚本，可载入当前页签或新页签。常用对象、SQL 收藏及字体、换行、缩略图偏好按账号、租户和数据库隔离，同一数据库的查询页签共享。
- 编辑器工具支持查找替换、切换行注释、选区优先格式化、跳转行号、字体缩放、自动换行、代码缩略图，以及 SQL 文件导入和下载。导入限 1 MB 的 `.sql` 文件，核对编码和预览后在新页签中打开，不自动执行。状态栏显示光标位置、选区和行数。

## SQL 报错位置

内置 Supabase 执行端仅在错误确实来自当前用户语句时返回相对原始请求的字符位置和原文。前端核对原文后，把 PostgreSQL 的一基 Unicode 码点位置转换为 Monaco 行列，支持中文、emoji、CRLF、多行及选区起点；能证实原文边界时保留 EOF 点位。结果区显示执行时 SQL 的准确行列和有界片段，不用空格模拟宽字符插入符。

会话设置、字段类型查询、事务结束、内部查询和控制台包装语句的错误不冒充用户 SQL 位置。旧式 `LINE n:` 报告只有完整 ASCII 原行可核对时才扣除前缀定位；独立 `Position:` 结合执行快照解析。外接执行端目前会重新排版 SQL，缺少原文映射时继续显示错误而不猜下划线。

执行时捕获编辑器实例与单调内容版本。响应晚到时，只有同一实例、同一版本、同一源码才设置标记；编辑后又恢复原文也不会复活旧标记。更换账号、租户或查询范围继续丢弃旧响应。验证覆盖 `tests/unit/sql-error-location.test.ts`、`tests/unit/sql-console-error-position.test.ts`、真实本地 PostgreSQL 的位置/handler 集成，以及 `tests/e2e/sql-error-location.spec.ts` 的 Monaco 实际标记。

## 查询历史预览与复用

“查询历史”保留当前账号、租户、连接和页签最近 30 次执行，只保存 SQL、状态、schema、时间与执行摘要，不保存结果。点击条目只展开完整只读预览，不修改草稿或自动执行；可复用代码预览的查找、换行和复制。无记录与搜索无匹配分别说明下一步。

预览中优先提供“在新页签打开”，保留原页签的 SQL 草稿并继承同一数据库连接；目标使用历史 schema，缺省 schema 则回到连接默认。“载入当前页签”明确替换当前 SQL 并清除旧结果，SQL 可通过编辑器撤销恢复，旧结果副本不保留。有本地结果修改时，两种载入均复用放弃修改确认；取消后草稿、schema 和结果副本保持不变。

查询执行中仍可预览，但载入动作禁用，完成或取消后再操作。最多 8 个页签，容量检查先于放弃修改确认；外接连接未就绪时不会将历史 SQL 回退打开到 Supabase。账号、租户、连接、页签、schema 或连接配置变化会失效待处理动作，同步切换后恢复原范围也不会复活旧动作。验证位于 `tests/e2e/sql-history-reuse.spec.ts` 与既有工作区、文件导入回归。

## SQL 文件编码与预览

文件在当前浏览器内存中读取，不上传文件或保存编码偏好。支持严格 UTF-8、UTF-16 LE/BE 和 GB18030（兼容 GBK）；有编码标记时默认选择对应编码，无标记时默认 UTF-8，不自动猜测旧编码。解码失败、编码标记冲突、空字符、空文本和不支持的编码标记会阻止确认，并提供切换编码、重试读取或重新选择文件的入口。同一文件可以再次选择。

只读预览最多显示前 100 行与 20,000 字符，按完整 Unicode 符号截取；超出时明确提示。确认传入完整解码文本，预览截断不会截断导入内容。解码保留空白和换行，预览统一显示换行；编辑器继续使用 Monaco 既有的换行规范化行为。导入不执行 SQL，也不替换当前页签内容。

读取中可以取消。账号、租户、权限、连接配置或查询页签发生变化时，清除待导入文件并丢弃迟到响应；同步切换后又恢复原范围也不会复活旧文件。达到 8 个页签或取消放弃本地编辑时，保留文件与编码供重试。验证位于 `tests/unit/sql-file-import.test.ts`、`tests/e2e/sql-file-import.spec.ts` 及原编辑器工具、长脚本导航回归。

## 结果与执行计划

执行时的信息栏显示浏览器已等待的秒数与本次请求实际发送的查询时限；执行中调整设置不会改写该快照。取消请求被接受后继续计时，直到数据库返回真实成功、失败或取消终态。结束后分别显示有效的执行端耗时和浏览器总等待，缺失、负数或非有限的执行端耗时不伪造为 0。浏览器总等待包含身份验证、网络、响应传输和客户端整理，不能把两者差值解释成纯网络耗时，也不显示进度百分比或结束倒计时。

计时通过单调时钟差值采样，不依赖每秒累加；后台节流后按实际等待时长更新。静态状态独立播报，动态秒数不进入 live 区域；窄屏信息栏可换行。账号、租户、权限、连接配置、页签和 schema 变化同步失效当前请求及计时，旧响应、错误、取消回执和 finally 不再修改新工作区；同一轮切走再返回原范围也不会复活旧任务。计时只留在当前页面内存，历史中的耗时仍是执行端值。验证位于 `tests/e2e/sql-execution-timing.spec.ts` 与已有取消、历史及错误位置回归。

结果底部提供 20 / 50 / 100 / 200 行本地分页，默认 50 行。总数是本次已加载的结果数；切页不重复执行 SQL，数据库返回上限与 SQL 自身 LIMIT 仍单独生效。导出菜单支持 Excel 与保留类型的 JSON，覆盖本次原始结果的全部已加载页。

右键结果单元格可“仅保留相同原值”或“排除此原值”；NULL 单独标明。筛选严格保留返回类型与完整原值，数字 `1`、文本 `"1"`、NULL、空字符串、空白和文本 `"NULL"` 分别匹配，不转换长整数或高精度十进制文本。最多 8 个条件同时满足，相同条件不重复加入；冲突条件可得到零行，条件仍可查看、移除或清除。对象、数组、缺失值、访问器、非有限数字和超出安全精度的整数不能作为筛选原值，菜单解释原因；重名字段需先在 SQL 中指定唯一别名。

全文搜索先处理获准业务字段，再按原值筛选、排序和本地分页；普通用户不可见的租户字段及未声明字段不参与搜索。用户主动隐藏的业务列仍参与全文搜索，但其原值条件会移除。表格复制覆盖筛选排序后的全部匹配页；图表、字段统计、比较基线和原始导出继续使用全部已加载原始结果。进入编辑副本、重新返回结果、账号、租户或查询范围变化时清除条件与旧菜单；不会执行额外 SQL 或持久化筛选。验证位于 `tests/unit/sql-result-value-filter.test.ts` 与 `tests/e2e/sql-result-value-filter.spec.ts`。

“编辑副本”使用 ArtTable 的通用编辑 API。表头显示字段类型，双击或 F2 打开仅用于 SQL 结果的宽幅类型编辑弹层：JSON 使用带高亮的编辑器并可格式化/放大；text 使用多行文本；boolean 和实际枚举值使用下拉；日期/时间支持原始文本、日历/时钟及当前时间。原始小数秒和时区文本保持不变，显式使用日历后才生成新值；JSON 格式化不转换数字精度。保留修改、NULL、撤销/重做、逐字段/全部还原、仅看修改、跨页保留修改和变更预览均作用于本地副本。编辑副本不写入数据库，不保存到浏览器存储；重新执行、切换查询页签/连接、清空和离开路由前会询问是否放弃修改，浏览器刷新使用原生离开提示。账号或租户改变时按安全边界清空结果。

SQL 结果显式开启 ArtTable 的 ElTableV2 虚拟分支，限制同时挂载的行节点数；与本地分页共同生效。其他页面默认保持原来的 ElTable 和行内编辑。

结果列保留按类型设定的最小宽度，UUID、JSON、文本和时间列不会为了塞入屏幕而收缩。超宽结果在表格内部横向滚动，底部滚动条保持可见；可拖动表头列边缘调整宽度，也可聚焦调整按钮后用左右方向键操作。

变更预览可查看原值/新值、定位或还原字段，导出变更 JSON。只有能确认单张基础表、直接字段映射和完整非空唯一主键的结果才能导出 UPDATE SQL；主键和已识别的租户字段禁止修改。视图、聚合、去重、CTE、联合/多表查询、计算列、重复字段、缺失/重复主键或不支持的字段类型会给出原因。数值编辑与生成保留十进制文本精度，JSON 做格式校验；SQL 值按方言编码，WHERE 包含主键、已修改字段的原值和已返回的租户字段。脚本默认以 ROLLBACK 结束，交由操作者核对影响行数后决定提交方式。

结果单元格使用紧凑摘要，点击或右键“查看”可打开完整详情，支持 JSON/SQL 高亮、文本搜索、匹配跳转、自动换行和复制。原始结果与导出内容不受摘要截断影响。执行计划保留原始数据库 JSON，同时显示估算路径；MySQL 与 PostgreSQL 的计划均不使用 ANALYZE，不会为了生成计划执行查询。

AI 生成会传递当前目标方言和已加载的元数据。外接模式不假设存在 Supabase 的平台用户表或 RLS，并只生成只读查询；用户仍须检查 SQL 后手动执行。

## AI SQL 预览与工作区保护

AI 生成和修复均先展示完整只读 SQL、摘要与提示，不自动写入编辑器，也不自动执行。普通用户仍可使用 AI；原始 SQL 执行权限保持原规则。生成期间需求和模式暂时禁用，发往模型的需求、模式、SQL、方言、连接类型和 schema 均使用点击时快照，元数据加载完成后不会混入新草稿。

生成结果可复制，或明确选择“在新页签打开”“载入当前页签”。前者保留原 SQL 草稿；后者会替换 SQL 并清除旧结果，SQL 可撤销恢复。生成期间编辑过的草稿仍保留并单独提示；预览不会因此被丢弃。存在结果副本修改时，两种载入均需通过原有放弃修改确认；取消会保留候选 SQL。确认等待中又编辑源码、关闭候选或切换范围时，旧动作不再载入。查询执行中、连接离线及 8 个页签上限分别说明原因并禁用对应载入方式。

执行计划、取消分析及 AI 请求共用工作区失效判断，并使用各自的请求序号。账号、租户、管理身份、页签、连接配置或 schema 改变时同步清理相应忙碌状态、计划与候选预览；同一轮切走再切回也不会接受旧响应。关闭后重开 AI 助手、重新生成或更换生成/修复模式同样失效旧候选；旧错误、取消回执和 finally 不得关闭新弹窗、清除新请求状态或写回 SQL。计划关联表的异步定位也在每次等待后核对范围。候选只留在当前页面内存。验证位于 `tests/e2e/sql-plan-ai-ownership.spec.ts`，以及普通用户 AI、原有取消和查询计时回归。

## 连接恢复与结果检索

执行端访问平台身份服务时优先使用进程已有代理配置；Windows 未配置环境代理时，继承当前用户已启用的静态系统代理。连接时限为 10 秒、单次身份请求总时限为 15 秒，避免代理 TLS 握手尚未结束就被原先的 5 秒上限中断。保留 HTTPS 证书校验，不修改操作系统代理设置。认证失效、权限不足、网络不可达分别返回稳定的错误码和对应恢复说明，网络故障不会再统一提示重新登录。启动器校验源码与工作目录指纹，拒绝静默复用旧版后台，并给出等待当前操作结束后重启的提示，不自动终止查询。

浏览器仅在执行端明确返回操作开始前的 `401 / PLATFORM_AUTH_REQUIRED` 时，共用一次会话刷新并重试一次；刷新前后必须是同一认证用户。普通 401、403、网络失败及不确定的保存/查询响应均不自动重放。连接失败自动展开高级设置，方便检查地址和复制启动命令；刷新失败清除已就绪状态。修改执行端地址、账号或租户后丢弃旧连接请求；表单参数变化后，旧测试结果不能再显示为新参数的连接成功。

结果工具栏提供本次已加载数据的本地搜索，支持字段值和 JSON 内容、不区分大小写；搜索及清空均回到第一页，无匹配时给出清空或换词提示。搜索不会执行 SQL，不改变数据库返回上限，Excel 导出仍包含全部已加载原始结果。进入编辑副本时清空搜索并恢复全部数据，避免筛选影响行定位和变更来源。JSON 文本详情复用不经过数值解析的格式化工具，保留大整数、高精度小数和原始指数表达。

## 取消查询与执行计划

执行中可点击“取消查询”，执行计划抽屉可点击“取消分析”。取消请求被接受后仍等待原查询的数据库终态，确认停止后才展示“已取消”，并在历史中单独记录；查询已先完成则保留成功结果。取消失败可重试，不将普通超时归为用户取消。

内置 Supabase 使用认证用户、租户范围、客户端请求 UUID 和执行端 lease 隔离短期请求登记。跨 Edge 实例的取消只设置状态，拥有原事务的执行实例向自己的数据库会话派发取消并等待回滚；浏览器不能提交数据库 PID。过早取消保留短期标记，重复请求编号不能再次执行，晚到取消不干扰后续查询。

私有登记有效期为 5 分钟，由该账号后续 begin/cancel 顺带清理；每账号最多 8 个活跃请求、1024 条登记，不保存 SQL、结果或 PID。数据库会话匹配使用 PID 与精确的 backend_start/xact_start，application_name 仅用于观测，SQL 改写该设置不影响取消。

外接 PostgreSQL 和 MySQL 分别使用独立控制连接取消原会话的语句，保持原会话到取消派发结束后再释放；硬超时与普通关闭也遵守该顺序，避免连接编号复用。取消请求重新校验账号、租户和连接授权，并可在普通查询并发额度用满时发送。达梦驱动当前没有可验证的主动取消接口，按钮明确禁用，仍由查询超时结束。切换页签仍按原有规则丢弃晚到响应，主动取消须在离开前操作。

验证覆盖：`tests/unit/sql-query-cancellation.test.ts`、`tests/unit/sql-console-cancellation.test.ts`、`tests/integration/sql-query-cancellation.test.ts`、`tests/integration/sql-console-cancel-driver.test.ts`、`tests/integration/sql-console-cancellation.sql`、`tests/e2e/sql-query-cancellation.spec.ts`。真实数据库验证包括慢查询活动消失、写事务回滚、并发额度用满后取消、权限隔离及晚到取消不影响新查询。

## 参数化查询 API

顶部“查询 API”提供授权接口列表、调用测试、接入说明和管理员配置。平台超级管理员可将当前内置 Supabase 语句“发布为查询 API”，填写稳定地址、用途、所属租户、参数定义和授权账号；新建在全部租户默认归管理员认证租户，选择具体租户时归该租户，编辑沿用原记录租户。外接数据库暂不提供 API 发布。接口可编辑和停用，不提供硬删除。

固定 SQL 使用 `:name` 绑定值，参数支持 string、number、boolean、date、uuid，不能绑定表名/字段名。字符串、注释、PostgreSQL cast 和 dollar 引号中的冒号不作为参数；拒绝多语句、写入 CTE、事务控制、锁及不支持的函数。数值参数可传十进制字符串以保留精度。启用保存前在只读事务中做 EXPLAIN 验证，不执行查询。地址创建后固定，修改使用原始微秒级版本做并发检查。

稳定消费接口为 `POST /functions/v1/sql-query-api/<slug>`，请求体 `{"params":{"name":"value"}}`。需要调用账号的有效 Bearer 令牌及项目公开 API key；接入页提供 URL、cURL 和 JavaScript 示例，仅使用占位值，不读取当前登录凭据。不能传 SQL 覆盖接口定义。

普通用户只可调用本租户内启用且明确授权的接口，不能发布、读取 SQL 或授权名单。服务端按实时启用账号、认证租户和接口授权校验；数据事务使用调用者的已验证 claims、`authenticated` 角色、只读模式和 RLS，数据范围固定为接口所属租户。平台全部租户可管理/选择接口，调用一个租户接口也只读取该租户；具体头部范围仍限制可管理/调用的接口。返回前再次检查配置、账号及授权，停用或修改期间的旧结果不交付。

每次最多 1000 行、30 秒、8 MB；跨实例限制全局 8 个、每账号 2 个并发和每分钟 60 次调用。私有配置、调用租约及审计不向普通角色开放，审计不记录参数和结果。调用结果复用结果表、图表和本地编辑副本。配置/账号/租户变化会清除旧 UI 结果并丢弃迟到响应。

### 查询 API 入门示例

调用测试开始后显示单调时钟计算的等待时间与本次超时快照；取消期间继续计时，只有原调用返回服务端取消终态才显示“调用已取消”。正常完成、失败和取消均冻结浏览器总等待时间。该值包含认证、网络和接口整理，不当作数据库纯执行耗时。所有调用按钮使用项目小尺寸控件。

页面为每次调用生成独立 UUID `requestId`，发送到原调用地址的 JSON 中；现有仅发送 `{params}` 的调用方式保持可用。取消请求使用根地址 `POST /functions/v1/sql-query-api`，JSON 为 `{action:"cancel",requestId,definitionId}`。返回 `cancel_requested` 仅代表接受请求，`not_running` 可能表示尚未登记，页面会在原调用仍有效时串行重试；`finished` 表示审计已结束，仍以原调用的最终响应为准。取消失败可以重试，成功先到时照常显示成功结果。

服务端只允许当前已验证账号取消自身、对应 API 且处于当前租户读取范围的调用；普通用户伪造租户头不会获得额外权限，平台超级管理员也不能通过此入口取消其他人的调用。API 停用或撤销授权后，原调用者仍可取消自己的在途请求。取消协调复用现有调用审计行，最终记录 `error/QUERY_CANCELLED`，无需新增表字段。执行进程持有独占事务，以后端 PID、会话起点、事务起点及应用标识核对后发出真实 PostgreSQL 取消信号；HTTP 不接受 PID。主 SQL 与 API 共用 `supabase/functions/_shared/query-cancellation.ts`。

更换 API、刷新定义、切换账号或租户、关闭重开及缓存页面停用会清除旧计时和待处理动作；旧结果、错误、取消回执与 finally 不能影响新调用。验证包括真实隔离 PostgreSQL 的 `tests/integration/sql-query-api.test.ts` 与 `tests/e2e/sql-query-api-cancellation.spec.ts`。

“使用说明与示例”解释用途和三个操作步骤：选择已授权 API、填参并明确调用、在接入说明中复制地址及代码。空列表时仍能学习；已有接口时可以展开或收起说明。打开示例只选择接口并填入参数，不自动查询；“填入示例参数”也不会更新已有结果，需再点击“调用 API”。

平台租户提供三条仅使用常量演示数据的接口，不读取业务表：

| 地址标识 | 示例参数 | 示例结果 |
| --- | --- | --- |
| `demo-hello` | `name: 亿企工场` | 返回问候语“你好，亿企工场” |
| `demo-order-amount` | `quantity: 3`、`unit_price: 19.90` | 返回精确金额文本 `59.70` |
| `demo-sales-trend` | `start_date: 2026-01-01`、`min_amount: 0` | 返回 7 天模拟销售额与订单数；最低金额改为 `2000` 时返回 2 行 |

演示接口每次最多 20 行、5 秒，默认不授予普通账号调用权；管理员可在“编辑与授权”明确授权同租户账号。普通用户只能打开服务端已授权的接口，学习区本身不会授予权限。接入代码始终使用凭据占位符，不复制当前会话令牌。

当前范围没有对应示例时，平台管理员可用“用此示例新建”预填草稿，再核对租户与授权并明确发布；新地址添加随机后缀以避免全局地址冲突，既有接口保持不变。通用接口仍使用按声明类型生成的示例值；已修改的 SQL 不会误认作原始演示查询。验证包括 `tests/unit/sql-query-api-samples.test.ts`、查询 API 浏览器回归和真实隔离 Postgres 上的 `tests/integration/sql-query-api.test.ts`。

## 长脚本编辑性能

Monaco 按模型、内容版本和数据库方言缓存一份语句索引，内容变化才重建；移动光标使用已分析的语句边界查找。显式选区继续按原语义独立分析，状态栏行数不因每次光标移动重扫全文。约 1 MB 基准中，首次建立索引约 51 ms，后续 40 次光标定位约 0.26 ms；原逻辑同样 40 次约 720 ms。这是词法定位基准，不代表整页渲染耗时。测试覆盖所有边界、方言、选区优先及修改版本失效。

共享 Edge 调用边界会捕获平台当前具体租户并携带请求头，会话刷新后的重试仍使用原请求范围；平台全部租户不强行回落到登录租户。ordinary 的伪造头仍由服务端认证边界忽略。

## 元数据目录与详情按需加载

当前 Supabase 首次只加载可读取的 schema 和表目录，不携带全库字段、索引、外键或函数。项目库实测从原约 3.11 MB 降到 96,250 字节（约减少 96.9%），目录构建约 57 ms；这是数据库构建与未压缩响应数据，不含客户端网络往返。函数级禁用该目录 RPC 的 JIT，未改全库配置。

展开表、打开结构、生成字段/主键/外键模板、结果副本编辑时才获取对应表详情；最多 32 表一批，按请求去重并缓存，详情更新保留树的展开状态。表详情包含可读取的双向外键，源表和目标表都保留权限检查。编辑副本先取完整主键/租户信息，未获取成功时阻止编辑而非放松锁定。

Monaco 补全与悬停按当前语句引用异步取字段，无需先展开对象树。模型版本、工作区范围或租户改变后，不交付旧请求的补全结果。目录失败时仍可用关键字并执行 SQL，不通过每次输入隐式重试；内联按钮提供明确重试。AI 在生成前按需求检索并加载最多 12 张相关表的完整字段，避免发送空结构或整个已浏览字段缓存。

对象搜索由服务端覆盖所有可读取表的名称、字段及注释，包含未展开对象；最多返回 100 张表与 100 个函数，并明确提示截断。函数按 schema 独立获取，最多 2000 项，截断提示对应到实际 schema。schema 列表包含只有函数或暂时没有表的可用命名空间。旧浏览器的无 mode 全量协议保持兼容；外接库继续按 schema 加载。

生产权限回滚验证覆盖平台全部/具体租户、普通用户及伪造头；新 RPC 使用 invoker 和原有 schema/table/function 权限谓词。跨租户晚到详情、目录失败重试、字段补全、普通用户 AI、结果编辑锁定及明暗/窄屏均有浏览器回归。认证会话缺失时，真实远程 HTTP 合同测试明确跳过，不以模拟会话冒充线上验收。

## 大型脚本语句导航

语句导航使用项目的 ElTreeV2 与 ElAutoResizer，仅渲染可见项，虚拟列表自己管理滚动。10417 条语句实测只挂载约 6–9 个按钮；搜索、末条跟随、方向键/Home/End、滚动后 Tab 和 Enter 定位保持可用，定位不自动执行。40 次光标切换与两帧稳定采样约 18–37 ms，原完整 DOM 的深色样本约 290 ms；该数据为一批交互，不能解释成单键延迟。

## 字段统计与数据质量

结果工具栏的“字段统计”按需加载，SQL 和查询 API 结果均可使用。统计覆盖本次全部已加载的原始行，不受本地搜索、分页或编辑副本影响，不额外请求数据库。返回上限会单独提示，结果不代表全表。

选择一个字段后才计算该列：NULL/缺失值、空字符串、纯空白、非 NULL 不同值、重复额外行数，以及常见值 Top 10。不同类型的值分别归类；空白通过带引号的摘要展示，比例以全部已加载行数为分母。对象、数组和超出归类边界的值不强行转成文本进行排名，归类不完整时明确标注。文本长度按 Unicode 码点计数。

数值类型提供有效值数、合计、最小、最大和平均值。十进制字符串在支持范围内精确计算，非终止平均值标注 `≈`；超出安全精度的 JavaScript 数值、非有限值、无效值及超出计算范围的值分别排除并解释原因。文本类型的数字不自动转换为数值。大文本与归类缓存有明确上限，计算分批让出界面，切列、关闭或数据替换时取消旧计算。

可下载当前字段统计 JSON，十进制值保留文本精度，不包含完整原始结果。统计仅保留内存；结果、账号、连接或租户替换会清除旧摘要。验证位于 `tests/unit/sql-result-profile.test.ts` 和 `tests/e2e/sql-result-profile.spec.ts`。

## 左右固定列与空间保护

普通结果工具栏的“固定列”可搜索当前显示的字段并选左侧、右侧或取消固定；表头和单元格右键也可直接操作。已隐藏字段保留固定设置，恢复显示后按空间重新应用。全隐藏后的恢复按钮只恢复字段；“重置列视图”才清除固定、显隐、顺序及实际列宽缓存。新结果、连接或租户范围替换会清除当前设置，不持久化字段或数据。

宽度预算来自虚拟表实际布局，包含弹性分配、拖动后的列宽和当前容器宽度。工作区小于 640px 暂停固定；存在未固定字段时为中间区域保留 240–320px，全部字段均固定且实际总宽放得下时无需预留中间区。新增固定若会挤掉已有固定或超出预算，拒绝本次操作并保留原设置。窗口收窄或拖宽后按请求先后稳定保留可容纳的固定列，其余暂停；扩大后自动恢复，不把字段自动隐藏。

编辑副本暂时解除固定，退出后恢复普通设置；编辑期间的工作区尺寸仍会更新，避免退出时使用过期宽度。固定只影响展示，不改变搜索、图表、统计、原始导出或副本编辑保护。窄屏仍可打开设置查看原因和取消已有固定。

SQL 结果显式采用虚拟平铺数据契约，`children` JSON 数组和 `hasChildren` 字段不被误识别为树行；筛选、校验和行映射只处理顶层记录并保留完整 JSON。其他业务表格默认树行为，以及显式树、展开、分组和合并等原生回退保持原契约。

验证包括 `tests/unit/sql-result-column-pins.test.ts`、`tests/e2e/sql-result-column-pins.spec.ts` 和 `tests/e2e/sql-result-flat-data.spec.ts`。固定策略位于 `result-column-pins.ts`，当前结果状态由 `use-sql-column-pins.ts` 统一维护。

## 两次查询结果对比

结果工具栏的“结果对比”可将当前已加载结果设为基线，再执行查询并打开对比；查询 API 调用结果也可使用。基线覆盖全部获准字段和已加载原始行，不受表格搜索、隐藏列或编辑副本影响；返回 0 行仍可比较。同一数据库与默认 schema 内可跨查询页签保留基线，切换账号、平台管理身份、租户、数据库或清空工作区会清除。API 定义、版本或启用状态改变时也会清除。快照只留在当前页面内存中，不写入存储、不重新执行 SQL。

对比必须选择双方共有且唯一的匹配键，支持组合键；不按行序匹配。重复、NULL、缺失、复杂值或超出安全精度的数值键会阻止计算并说明原因。新增、缺失、修改和未变分别计数；字段新增、移除及声明类型变化独立展示。比较保留值类型、文本精度和缺失值语义，对象键顺序不影响结果，数组顺序会影响。已经在传输中丢失的数值精度无法恢复。

行详情可查看前后字段、所在行及完整匹配键，长文本提供原文查看；对象和数组以保留类型的表示展示。筛选只影响列表，下载的对比 JSON 包含完整差异及类型信息，不包含未变行的原始值。双方只比较已加载范围；达到返回上限时单独提示，缺失不能解释为数据库物理删除。每份快照最多 1000 行、4096 字段、估计 8 MiB，超出范围会拒绝保留，不静默截断。

算法和快照边界位于 `result-compare.ts`，入口状态由 `result-comparison-controls.vue` 管理，抽屉按需加载。验证包括 `tests/unit/sql-result-compare.test.ts` 与 `tests/e2e/sql-result-comparison.spec.ts`。

## 原始结果导出

SQL 和查询 API 共用“导出结果”入口，支持 Excel 与 JSON（保留类型）。导出全部已加载的获准原始字段与行，不受本地搜索、分页、隐藏列、固定列或编辑副本影响；不会额外执行 SQL。只返回 0 行但提供字段元数据时，Excel 生成仅表头文件，JSON 保留字段信息与空行数组，不伪造数据。

Excel 面向查看，单元格采用文本以保留高精度数字、JSON 原文和公式形文本；NULL 显示为 `NULL`。若要区分 NULL、文本 `"NULL"`、缺失、undefined、数值与文本，请选择 JSON。JSON 使用 `sql-result-snapshot` 格式，包含版本、保留时间、字段顺序、来源、已加载行数、截断标记和保留类型的行编码；对象通过 `entries` 编码，避免数据自身的类型标签发生冲突。普通用户 API 导出不包含接口 SQL。

两格式均先建立有界独立快照，复用结果对比的行数、字段数、内存及对象结构限制。达到返回上限会在菜单及 JSON 元数据中提示，文件不代表数据库全量。账号、租户、数据库、API 版本、当前结果或可用状态变化会中止旧导出；Excel 动态加载结束后仍在落文件前检查，过期任务不下载也不显示成功提示。

共享 Excel 工具通过显式表头保留声明列顺序，数字形式和 `__proto__` 等名称也作为普通列处理；`allowEmpty` 仅由需要零行字段信息的调用方显式开启，其余页面维持空数据拒绝导出的行为。验证位于 `tests/unit/sql-result-export.test.ts`、`tests/unit/file-export.test.ts` 和 `tests/e2e/sql-result-export.spec.ts`。

## 复制当前结果视图

结果工具栏的复制图标提供“复制表格”和“复制 TSV”。复制当前筛选后全部匹配的已加载行，跨所有本地分页，包含表头；字段只取当前显示的获准字段，并遵循列重排及实际生效的左右固定顺序。筛选为 0 行时仍可复制表头。复制不会重新执行 SQL，也不包含编辑副本；原始 Excel/JSON 导出仍保留全部获准原始字段、行及查询原序。

“复制表格”通过一个原生剪贴板项提供 HTML 表格和 TSV 纯文本；不支持表格格式时需明确选择 TSV，不会在权限失败后自动降级或显示成功。单元格按原值文本生成，高精度数字字符串和前导零不经过数值转换，HTML 内容作为普通文本转义。NULL 显示为 `NULL`，缺失/undefined 显示为空，因此需要区分类型时应使用 JSON 导出。

接收应用决定粘贴时的单元格类型。Excel 请先将目标区域设为文本，避免长数字、前导零或公式形文本被自动识别；重要精度与类型请使用现有 Excel/JSON 导出。TSV 使用制表符分列、CRLF 分行，含制表符、换行或引号的字段使用双引号包围并重复内部引号。

复制复用有界独立快照，并限制 HTML 与 TSV 合计 1 MiB、单元格最多 32767 个 UTF-16 单元，拒绝 NUL 与不完整 Unicode；超限会说明缩小筛选或使用导出，不静默截断。账号、租户、结果来源、可用状态或显示范围变化会中止未完成准备并丢弃旧成功提示；操作系统已完成的剪贴板写入无法撤回。格式边界和真实浏览器双格式读取验证位于 `tests/unit/sql-result-clipboard.test.ts`、`tests/unit/clipboard-formatted.test.ts` 和 `tests/e2e/sql-result-clipboard.spec.ts`。

## 特殊字段与原值一致性

数据库结果字段允许与 JavaScript 方法或 Vue 标志同名。显示、搜索、单元格详情、类型推断、图表、字段统计和导出统一通过 `getOwnRecordValue` 读取实际自有数据属性，不读取继承方法、不执行 getter，也不把 `__v_isRef`、`__v_raw` 等业务数据当作框架状态。嵌套 JSON 保留完整对象，不自动解包其 `value` 字段。

进入编辑副本前先建立有界独立快照，只保留结果声明的字段，再进行既有 JSON 和数值文本转换；未声明的额外属性不进入副本或变更文件。已有 `__proto__`、`constructor` 等字段作为字面字段安全修改，并支持撤销、重做与还原；缺失的危险嵌套路径仍禁止创建，主键与租户字段锁定保持不变。

比较报告、选中单元格和详情仅对界面状态使用浅响应，原始数据保持独立；表格回调按稳定标识找回对应原始记录。快照验证、复制及类型编码使用同一套属性描述符，避免验证后再次读取代理对象而改变值。通用业务表格继续保留原有嵌套路径、数组与 Ref 的响应行为，不将 SQL 的字面字段规则全局套用。

验证包括 `tests/unit/record.test.ts`、`table-edit-model.test.ts`、`sql-result-edit.test.ts`、`sql-result-compare.test.ts`、图表/统计专项，以及 `tests/e2e/sql-result-export.spec.ts`、`sql-result-comparison.spec.ts` 的实际编辑、详情和下载场景。

## 已加载结果本地排序

普通 SQL 和授权查询 API 结果可点击字段表头排序，也可聚焦表头按钮后按 Enter 或空格，依次切换升序、降序和查询原序；“恢复查询顺序”随时清除当前排序。先筛选、再对全部匹配的已加载行排序，最后进行本地分页，不重复执行 SQL，也不只排序当前页。排序变化回到第一页和表体顶部，同值稳定保留查询相对顺序。

数值字段使用十进制比较，不经 Number 转换高精度文本或 BigInt；单个 BIT 支持 0/1，布尔字段严格比较 false/true，文本不自动转换数字并采用中文排序规则。文本规则不承诺与数据库 collation 一致。NULL/缺失值始终置后；无效、异型、不安全或超出比较边界的值保持相对顺序置后，并单独显示未参与比较的数量。JSON、数组、二进制和区间等复杂类型不提供排序入口。

常见 ISO 日期、时间和时间戳按实际时间值比较，支持公元 0100–9999 年、最多 9 位小数秒及 ±14:00 内的明确偏移。不带时区值按本地日历值比较，不使用浏览器时区推断；同字段混合带时区和不带时区时拒绝猜测并保持查询原序。只有时间的带偏移值按同一参考日比较，不推断日期或跨日循环。未知偏移、无效日期、超出支持范围的格式会计入未比较数量。

排序只保留在当前结果内存中。隐藏当前排序字段时清除排序，列重排不改变偏好；进入编辑副本时使用原始行序并暂停排序，退出后恢复。新结果、连接、账号或租户变化会清除排序。原始导出、图表、统计和结果对比继续使用完整原始数据与原序。SQL 表格使用本地行引用标识，因此重复或 NULL 的业务 id 不会导致排序后丢行；更新 SQL 的主键唯一性检查仍使用真实数据库字段。

策略位于 `result-sort.ts`，状态与表头同步由 `use-sql-result-sort.ts` 管理。数值文本最多 4096 字符，文本值最多 1 Mi 字符，超限不会静默截断比较。验证包括 `tests/unit/sql-result-sort.test.ts` 与 `tests/e2e/sql-result-sort.spec.ts`，覆盖跨页排序、精度、时区、稳定顺序、键盘与标准 ARIA、编辑暂停、作用域清理和原序导出。

## 查询 API 个人参数方案

调用区的书签小图标“参数方案”可将已填参数保存到本机，便于重复查询。方案按项目、账号、当前租户范围与 API 隔离；普通授权用户同样可用。明确点击“保存当前参数”并命名后才保存，一键填入只替换表单，不调用接口，也不刷新已有结果。查看详情保留数值文本、空白字符串及 false；可以保存尚未填完必填项的方案，实际调用时仍执行原有必填和类型校验。不要在共享浏览器保存敏感参数。

每个 API 最多保存 10 份，名称去除首尾空白后为 1–32 个字符，同名方案需使用“用当前参数更新方案”；每个文本值最多 4000 个 UTF-16 单元，单份存储状态最多 64 KiB。数值继续按文本保留精度，空字段省略。更新和取消保存只改变本机个人快捷项，不修改 API 定义、授权或数据库记录。

参数签名按名称、类型、必填规则生成，单纯调整参数顺序不影响兼容；API 版本变化时提示核对后再调用，参数签名改变则暂停旧方案的填入，允许查看及用当前参数更新。账号、租户、接口、版本、会话或调用状态变化会使旧弹层和保存动作失效。

保存后先检查物理存储写入回执，空间不足或存储权限受限时保留输入和旧有效方案并显示中文反馈。缓存损坏可重新读取，仍无法恢复时明确确认重置当前 API 的本机方案；确认期间其他页面已修复或更新的内容不会被清除。存储不包含登录令牌、SQL、授权配置或结果集，不触发远程写接口。核心校验与界面回归位于 `tests/unit/sql-query-api-parameter-presets.test.ts` 和 `tests/e2e/sql-query-api-parameter-presets.spec.ts`。

## 查询 API 接口规范

“接入说明”顶部提供两个小图标，可预览或下载当前已授权查询 API 的 OpenAPI 3.1 JSON，文件名为 `<slug>.openapi.json`。下载后可交给开发者或导入支持 OpenAPI 3.1 的接口工具，填写自己的有效访问令牌和项目公开 Key，再明确发送请求。生成规范不会调用接口或执行 SQL，普通授权用户和管理员均可使用。

规范只包含当前业务 POST 地址、公开名称与说明、参数规则、返回上限、超时及启用状态。不会导出 SQL、接口/账号/租户编号、授权名单、当前登录凭据、个人参数方案、当前输入或查询结果。认证在同一个 security requirement 中要求 Bearer JWT 与 apikey；项目公开 Key 放在 apikey 头，用户访问令牌放在 Authorization 头。认证语义依据 [Supabase Authorization headers](https://supabase.com/docs/guides/functions/auth-headers)，规范结构依据 [OpenAPI 3.1](https://spec.openapis.org/oas/v3.1.1.html)。

精确数值优先使用十进制字符串，按现有服务端规则描述长度、指数和安全 JSON 数值范围；可选参数允许省略或传 null，必填参数不允许 null。文本长度的服务端限制以 UTF-16 单元计数，使用明确说明与扩展字段，不冒充 JSON Schema 的 Unicode 字符长度限制。业务结果字段未声明类型，因此 rows 以通用对象描述，不用当前结果猜测业务字段结构。HTTP 200 区分正常结果与取消终态；认证网关及业务错误均保留其实际响应区别。

API、版本、启用状态、账号、租户、调用状态及缓存页面状态变化会关闭旧预览并清理旧错误；重新打开后按当前定义生成。已停用接口仍可只读查看规范，调用权限和是否可执行始终由服务端重新校验。此规范仅描述业务调用地址，不包含发布、授权或取消管理操作。

## 代码预览复制的生命周期

SQL、API 示例、OpenAPI 规范等共用的代码预览在复制期间显示原尺寸的忙碌图标并阻止重复提交，只在当前有效原生或显式兼容写入确认后显示成功。代码、标题、语言、所属弹层会话、账号/租户/API 范围变化，以及关闭、折叠、缓存停用或卸载都会使旧任务失效。即使新页面重新显示相同文本，旧任务也不能修改新按钮状态、触发提示或清除新任务的忙碌状态。

共享文本复制工具新增可选 AbortSignal，在进入写入、接收原生回执以及进入兼容分支前检查取消。原生失败后若任务已失效，不会再创建旧内容的 textarea 或执行兼容复制；当前有效任务仍保留原有兼容能力和失败重试。已交给浏览器或操作系统的原生写入无法撤回，这里的失效保护约束后续写入与界面回执。

预览直接复用 Art 弹层提供的实际会话版本；单元格/规范查看与 API 调用区另在数据范围重置前同步取消子预览，覆盖同内容、同账号返回的 ABA 场景。验证包括 `tests/unit/clipboard-text-cancellation.test.ts` 和 `tests/e2e/sql-code-copy-lifecycle.spec.ts`；原实现的失败基线与修复证据保留在忽略的构建产物目录。
