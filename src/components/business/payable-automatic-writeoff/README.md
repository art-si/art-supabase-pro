# 按方案自动核销

`open({ schemeId, date, query })` 打开匹配预览；方案必须已启用自动核销。查询范围、方案所属租户和权限均由服务端重新校验。

确认携带预览指纹。余额或方案使清单变化时禁止执行，保留弹窗并要求重新预览。仅核减会计余额，不发起银行付款；成功后发出 `success`。确认响应失败时结果可能尚未确认，发出 `refresh` 让调用方重查记录，不把网络失败宣称为服务端必定未执行。

使用共享 ArtDialog、ArtSectionCard 和 ArtTable，包含加载、空态、错误重试及重复确认保护。当前服务端仅处理人民币应付付款关系；其他关系不得伪装为该入口。
