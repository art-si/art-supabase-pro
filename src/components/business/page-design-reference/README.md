# PageDesignReference

用于全局头部中的平台超级管理员个人设计参考标记。组件读取当前稳定路由名，把当前路由对应的整个模块标记为 AI 后续页面设计的风格参考。

## 使用边界

- 只由 `ArtHeaderBar` 接入，固定放在“刷新当前页面”右侧。
- 仅平台超级管理员渲染入口并发起请求；数据库 RLS 同样只允许平台超级管理员读写本人记录。
- 星标按钮打开设计参考弹窗，可选择快捷标签、填写备注，并上传或直接粘贴最多 6 张参考截图。
- 标记范围是整个路由模块；截图保存在平台超级管理员专属的私有 Storage bucket，数据库只保存附件元数据。
- 不自动采集 DOM 文本、表格内容或业务记录；只有管理员主动添加的截图和描述会进入设计记忆。

## 使用

```vue
<PageDesignReference />
```
