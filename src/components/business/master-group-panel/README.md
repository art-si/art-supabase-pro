# MasterGroupPanel

公共主数据分组导航。供应商、项目/客户/工序主数据、工艺路线、TMS 客户及货物使用同一组件；页面只负责数据、当前选择、权限与业务事件。

## 布局

与 `ArtWorkspaceSplitter` 配合，使用 `:breakpoint="900"` 和 `stacked-primary-size="auto"`。不要在业务页固定手机分组区域的高度或重复实现响应式双栏网格。

- 大屏保留完整分组树，并由工作区限制高度。
- 900px 及以下默认收起，显示当前分组、节点数及加载/失败信息。刷新和已授权的新增入口保持可用。
- “展开分组 / 收起分组”支持键盘操作与 `aria-expanded`，切换保留关键词、树展开状态和当前选择。展开后的长树使用内部滚动，不占满整个页面。
- 窄屏管理按钮直接可见，采用 44px 触屏点击区域；桌面仍可通过悬停或键盘聚焦显示节点操作。

`managePermission` 为空时仅提供导航和刷新。存在时仍由原有按钮权限控制新增、编辑、删除；组件只发出事件，删除检查与确认由业务页面的公共删除保护流程负责。

加载、空数据、错误及重试继续由 `ArtSectionCard` 管理。收起状态不创建第二套树或数据请求。
