# ArtAddressPicker

区域、详细地址与地图选点共用的地址控件。业务表单通过 `v-model:region-path`、`v-model:address-detail`、`v-model:longitude`、`v-model:latitude` 等具名模型承接地址与坐标。

## 输入与操作

- 桌面详细地址与“当前位置 / 地图选择”共用一层背景、圆角、焦点和错误轮廓，内部按钮不产生独立投影。
- 整体外观复用工作区 `--art-control-*` 变量，跟随浅色、深色及边框、阴影模式。禁用与定位中仍保留各自的交互状态。
- 600px 及以下，操作按钮沿用下方独立一行布局，避免挤占地址输入宽度；保留键盘焦点、可访问名称与图文居中。

## 地图初始视野

- 有有效业务坐标时回显原位置；无业务坐标时先显示地图，再异步获取设备当前位置作为初始视野，不再固定到某个城市。
- 初始定位只改变视野，不回填地址或保存经纬度。“当前位置”操作或确认地图选点才会更新业务模型。
- 用户搜索、选点或拖拽后，迟到的初始定位不能抢回视野；关闭、重开和卸载会取消旧请求。
- 定位失败显示中文提示，仍可搜索和手动选点。搜索将本次输入值直接传入防抖任务，避免依赖父级模型同一轮更新的时序。

## 验证

`tests/e2e/address-input-style.spec.ts` 验证真实 workspace 下三种宽度、浅深主题与两种盒子模式，包括焦点、错误、禁用及定位中状态；`tests/e2e/address-map-lifecycle.spec.ts` 验证自动搜索、默认定位、业务坐标回显和异步请求隔离。
